# 🩺 WB JEPBN 2026 – Online Mock Test Platform

An interactive, subject-wise online mock test platform designed for candidates preparing for the **West Bengal Joint Entrance Examination for Post Basic B.Sc. Nursing (WB JEPBN)**.

The platform provides previous-year question paper practice and subject-wise mock tests to help nursing aspirants improve their preparation, test their knowledge, and evaluate their performance.

## 🌐 Live Website

**[WB JEPBN 2026 Mock Test – Open Website](https://wb-jepbn-2026-mock-test-techno-sb.netlify.app/)**

## ✨ Features

- **Previous Year Question Papers (PYQs):** Practice WB JEPBN question papers from 2021 to 2025.
- **Subject-wise Mock Tests:** Practice questions from multiple nursing and allied subjects.
- **Interactive Quiz Interface:** User-friendly interface for attempting questions.
- **Timer-based Tests:** Practice with a time-based examination environment.
- **Instant Test Evaluation:** Submit the test and view your performance.
- **Dark Mode:** Switch between light and dark themes.
- **Responsive Design:** Access the platform from desktop and mobile browsers.
- **Easy Navigation:** Select your preferred subject or previous-year paper from the dashboard.

## 🚀 Getting Started

You can run this project locally without installing any additional software or dependencies.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/WB-JEPBN-2026-Mock-Test.git
```

### 2. Open the Project

```bash
cd WB-JEPBN-2026-Mock-Test
```

### 3. Run the Website

Open the `index.html` file in your preferred web browser.

Alternatively, use the **Live Server** extension in Visual Studio Code.

## 🎯 Project Objective

The primary objective of this project is to provide a simple and accessible online practice platform for WB JEPBN aspirants.

It aims to help students:

- Revise important nursing subjects.
- Practice previous-year questions.
- Improve time management.
- Assess their preparation through mock tests.
- Build confidence before the examination.
